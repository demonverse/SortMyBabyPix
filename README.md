# SortMyBabyPix
Python script for a particular task: organising my media in year order.  Takes media on 1 or 2 USB sticks and files to a third, by date and year from exif data (if available)
You create the target:/Photos and target:/Videos and the robot creates the years & sorts
Added: Script to extract everything that is not a video or photo into folder you create :/Spares
